This repository hosts the source code of my personal portfolio website: a single-page site designed and built with Claude in plain HTML, CSS and JavaScript. It covers my background, publications & projects, news, and contact info.

## Design & build process
The visual design and design system (colour palette, typography, card/section layout) were created with Claude Design, then implemented into this repository with Claude Code.

## Structure
- `index.html`: the page content.
- `design-system.html`: a living style guide (colours, type, spacing, components, rules).
- `css/style.css`: all styles, with the colour, type and spacing tokens at the top.
- `js/main.js`: interactions, mobile menu, scroll spy, Background slider, News accordion, Paris clock, copy e-mail.
- `font/`: Sonder (display font) and Hanken Grotesk (body font, fallback).
- `img/`: portrait, logo, favicons, News photos.
- `resume/`: the resume linked from the Contact section.
- `CLAUDE.md`, `.claude/`: project notes and a Claude Code skill, kept for whoever picks this project back up.
